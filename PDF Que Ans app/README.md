# 📄 AI PDF Question Answering App

An AI-powered Streamlit application that allows users to upload PDF documents and ask questions from the content using OpenAI and LangChain.

---

## 🚀 Features

- Upload PDF files
- Ask questions from PDFs
- AI-generated answers
- Streamlit UI
- OpenAI integration
- Vector search using FAISS

---

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- OpenAI
- FAISS
- PyPDF2
